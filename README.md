# DeskDrop

## Internal Office Resource & Asset Booking System

DeskDrop is a MERN-based internal office resource and asset booking system that helps employees view, book, and manage shared office resources while preventing scheduling conflicts.

## Problem Statement

Office employees often face communication overhead, ghost bookings, and scheduling conflicts when reserving shared resources.

## Solution

DeskDrop provides a centralized platform where employees can:

- View office resources
- Check availability
- Select date and time slots
- Book resources
- View their bookings
- Cancel bookings
- Avoid double bookings

Administrators can add, edit, and delete resources.

## Key Features

- User Signup & Login
- JWT Authentication
- Resource Catalog
- Resource Availability
- Resource Booking
- My Bookings
- Booking Cancellation
- Conflict Detection
- Admin Resource Management

## Tech Stack

- React
- Vite
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
